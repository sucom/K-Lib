Download K-Lib

There are a few easy ways to quickly get started with K-Lib, each one appealing to a different skill level and use case. Read through to see what suits your particular needs.

Compiled JS

The fastest way to get K-Lib is to download the compiled and minified versions of the library. No documentation or original source files are included.

Download K-Lib

Additional downloads

K-Lib's hard dependencies are jQuery(>=1.10.2) and underscore.js (>=1.5.1)
  • jQuery
  • underscore.js
Also, you may need the following libraries if you intend to use K-Lib for rendering UI with respective framework/library.
  • Backbone
  • Thorax
  • Handlebars
  • Mustache
  • jquery-tmpl
  • jsrender
  • dust
  • hogan
  • transparency
  • weld
  • doT
  • tjs

What's included

Within the download you'll find the following directories and files, providing both compiled and minified variations.

Once downloaded, unzip the compressed folder to see the structure of K-Lib. You'll see something like this:

klib/
    ├── js/
    │   ├── klib.js       | for development use, with comments + debugging info
    │   ├── klib.min.js   | for production use, NO comments, NO Debugging info

This is the most basic form of K-Lib: compiled files for quick drop-in usage in nearly any web project.

jQuery and underscore are required

Please note that K-lib requires jQuery and underscore to be included, prior to K-Lib.js

Basic template

Make use of a super basic HTML template to get started.

Copy and paste the HTML from below to get started with a bare bones K-Lib document.

<!DOCTYPE html>
<html>
  <head>
    <title>K-Lib Boilerplate</title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- HTML5 shim for IE8 support of HTML5 elements -->
    <!--[if lt IE 9]>
          <script src="//cdnjs.cloudflare.com/ajax/libs/html5shiv/3.6.2/html5shiv.js"></script>
        <![endif]-->
  </head>
  <body>
    <h1>Hello, world!</h1>

    <!-- jQuery & underscore (necessary for K-Lib) -->
    <script src="//code.jquery.com/jquery.js"></script>
    <script src="//cdnjs.cloudflare.com/ajax/libs/underscore.js/1.5.1/underscore-min.js"></script>
    <!-- Include K-Lib -->
    <script src="js/klib.min.js"></script>
  </body>
</html>

Browser support

K-Lib is built to work best in the latest desktop and mobile browsers, meaning older and less advanced browsers might not work as expected.

Supported browsers

Specifically, we support the latest versions of the following:

  • Chrome (Mac, Windows, iOS, and Android)
  • Safari (Mac and iOS only, as Windows has more or less been discontinued)
  • Firefox (Mac, Windows)
  • Internet Explorer

Unofficially, K-Lib should behave well enough in Chromium for Linux and Internet Explorer 7, though they are not officially supported.

Internet Explorer 8 and 9

Internet Explorer 8 and 9 are also supported, however, please be aware that many CSS3 properties and html 5 attributes like placeholder are not supported in either of these versions. visit HTML5 Test for capability check.

IE Compatibility modes

K-Lib may not be supported in the old Internet Explorer compatibility modes. To be sure you're using the latest rendering mode for IE, consider including the appropriate <meta> tag in your pages:

<meta http-equiv="X-UA-Compatible" content="IE=edge">

See this StackOverflow question for more information.

Third party support

We don't officially support any third party plugins or add-ons.
