Render

klib.render(viewContainderId, options) : returnData

viewContainderId: String; (jQuery Selector String with #)

options: String; JSON Object 

{
data: {}
// Data(JSON Object) to be used in templates;
// for HTML inline data-attribute see dataUrl

,dataUrl: ""
// External Data(JSON) URL or local:dataModelVariableName

,dataUrlErrorHandle: ""
// Single javascript function name to run if external data url fails; NOTE: (jqXHR, textStatus, errorThrown) are injected to the function.

,dataParams: {}
// dataUrl Params (NO EQUIVALENT data-attribute)

,dataModel: ""
// External Data(JSON) "key" for DataObject;
// default: "data"; may use name-space x.y.z (with the cost of performance)

,dataModelType: ""
// "Backbone" | "Thorax" applicable only for local data
// ex: data or dataUrl:"local:XXXXXX"
// dataModelType:"Backbone:BackboneOptions"
// BackboneOptions (String)
   var backboneOptions = "{ classpath:'path-to-backbone-model-class.js'"
                        +", classsuccess:jsFn4ClassSuccess"
                        +", classerror:jsFn4ClassError"
                        +", defaults:{}"
                        +", fetchsuccess:jsFn4FetchSuccess"
                        +", fetcherror:jsFn4FetchError"
                        +"}";

   function jsFn4ClassSuccess(classUrlResponse){}
   function jsFn4ClassError(classUrl, jqXHR, textStatus, errorThrown){}
   function jsFn4FetchSuccess(model, response, options){}
   function jsFn4FetchError(model, response, options){}

,dataCache: false
// External Data(JSON) Cache

,dataTemplatesCollectionUrl: ""
// location of single file containing all the templates;
// helps to load all templates in single request.
// use "dataTemplate" to define primary tempate to be used for rendering

,dataTemplates: {}
// Templates to be used for rendering
// ex: {tmplID:'inline', tmplID:'script', tmplID:'URL'}

,dataTemplateEngine: ""
// handlebars | underscore | underscore-as-mustache | mustache | jqtmpl | jsrender | dust | hogan | transparency | weld | doT | tjs

,dataTemplate: ""
// Primary Template ID ==> content may be inline or <script>
// dataTemplate = dataTemplates[0]; if dataTemplate is not defined

,dataScripts: {}
// scripts (js) to be loaded along with templates
,dataScriptsCache: true
// cache of dataScripts

,dataStyles: {}
// styles (css) to be loaded along with templates
,dataStylesCache: true
// cache of dataStyles

,dataRenderEngine: ""
// jqTmpl | Backbone | Thorax | jsRender | dust (| dustRender) | dustStream
,dataRenderCallback: ""
// single javascript function name to run after render

,dataViewId: ""
// Used only for RenderEngine:Thorax, to locate in Thorax.Views collection
,dataRenderId: ""
// Render Id, may be used to locate in klib.renderHistory[dataRenderId],
// auto-generated key if not defined
,dataWeldConfig: {}
// Weld Template Configuration Optional

}

returnData: JSON Object 

{
  id: String
  //value of input:dataRenderId or auto-generated-unique id
  //may be used to locate in klib.renderHistory[id]
, view: {}
  //view object used in render;
  //useful if renderEngine: {backbone | thorax}
, model: {}
  //model object used in render;
  //useful if renderEngine: {backbone | thorax}
, cron: String
  //Timestamp
}

<div id="memberList"
      data-url="/api/member/list.json"
      data-templates="{tmplMemberList:'/templates/member/list.html'}"
      data-template-engine="handlebars"
      ></div>

      klib.render("#memberList");

klib.viewModels : { }

This is a local storage data collection object, which stores all rendered data models with "dataRenderId" key.


      klib.viewModels["123456789"];
      //==> dataModel of render call with dataRenderId="123456789"

klib.renderHistory : { }

This is a local storage render collection object, which stores all rendered views and models with "dataRenderId" key

NOTE: The return value of each klib.render() call being stored in this collection object. This storage is limited by "klib.renderHistoryMax" variable. The old rendered values (views and models) will be removed when history reaches Max limit.


  klib.renderHistory["123456789"];
  Returns:
{
  id: "123456789"
  , view: {}
  , model: {}
  , cron: "1378275471876"
  }

klib.renderHistoryMax : Integer

The maximum limit for storing render history. Default: 100


      klib.renderHistoryMax = "50";
      //==> Changes the render history max length to 50

tmplId: String; Unique Template Id (without #)

[templateType: String] Default: x-template

  content of "/templates/memberView.html" comes here...
  </script>

  <div id="divMemberDetails">
  </div>

  <script id="tmplMemberDetails" type="text/x-handlebars-template">
  Hello {{ name }}!
  </script>

JSON

klib.setObjProperty(obj, keyName, value, keyNameToLowerCase)

obj: JSON Object

keyName: String; { camelCase(keyName) | TitleCase(KeyName) | withCharDelimiter(Key_Name | key.name | key-name)}

value: {String | Integer | Float | Boolean | Array | Object}

[keyNameToLowerCase: Boolean]; default: false 


      klib.setObjProperty({}, "name", "Jack Black");
      //==> { name: "Jack Black" }

      klib.setObjProperty({}, "Address_Shipping_State", "New York");
      //==> { Address: {Shipping: {State: "New York" } } }

      klib.setObjProperty({}, "address-shipping-state", "New York");
      //==> { address: {shipping: {state: "New York" } } }

      klib.setObjProperty({}, "address.shipping.state", "New York");
      //==> { address: {shipping: {state: "New York" } } }

      klib.setObjProperty({}, "address>shipping>state", "New York");
      //==> { address: {shipping: {state: "New York" } } }

      klib.setObjProperty({name: "Jack Black"}, "AddressShippingState", "New York");
      //==> {name: "Jack Black", Address: {Shipping: {State: "New York" } } }

      klib.setObjProperty({name: "Jack Black"}, "addressBillingState", "CA", true);
      //==> {name: "Jack Black", address: {billing: {state: "CA" } } }

klib.initKeyTracking([elementSelector: String])

[elementSelector: String] jQuery Element Selector; default: "[data-disable-keys],[data-focus-next],[data-focus-back]"

Use this

  • to prevent keys on specified elements
  • to set focus next (Tab Key) to the specified element
  • to set focus back (Shift+Tab Key) to the specified element
for javascript key codes refer
  • http://www.cambiaresearch.com/articles/15/javascript-char-codes-key-codes
  • http://unixpapa.com/js/key.html
  • http://whatthekeycode.com/
  • http://www.asquare.net/javascript/tests/KeyCode.html
NOTE: use with caution as it does not work as expected in some browsers! 


<input type="text" name="userName" id="userName" value="" data-disable-keys="191,220,189" />

klib.initKeyTracking("#userName");
// Disabled keys are forward-slash(/), back-slash(\) and dash(-)
